### socket
#### socket.py
- класс `Socket2`, наследует `AbstractConnection`
  - `__init__` адрес, таймаут, длина пакета

### abstract.py
- класс `AbstractDevice`
  - `connection, connection_type` Переменные для хранения объекта сетевого или COM-подключения и его типа.
  - `dev_name, dev_addr, dev_type` Идентификационные данные прибора (имя, адрес, тип).
  - `timeout` Время ожидания ответа от прибора.
  - `status` Текущее состояние устройства.
  - `channels` Заданное количество каналов
  - `__init__` конструктор класса, изначально устанавливает класс подключения в None
  - `set_connection` Cохраняет переданный тип соединения в переменную self.connection_type
  - `set_addr` Задает физический или сетевой адрес устройства (ip address:port или com port).
  - `set_baudrate` Передает заданную скорость передачи данных напрямую во внутренний объект соединения.  сработает только после подключения, до этого будет ошибка
  - `connect` Ключевой метод установки связи. Создает реальный объект соединения, передавая ему адрес и таймаут. При успешном соединении статус переводится в 'idle' (свободен/ожидает команд).  
  - `close` Закрывает физическое соединение и сбрасывает статус прибора обратно в 'init'.
  - `send` Отправляет данные на прибор.
  - `read` Читает ответ от прибора из буфера.
  - `read_len` Читает строго заданное количество байт.
  - `read_len2` Альтернативный метод чтения заданной длины, вызывающий read2 у объекта соединения.
  - `io` Отправляет данные и сразу ждет ответа.
  - `io_raw` Отправляет сырые данные и сразу ждет ответа.
  - `init` Этот декоратор обязывает, при создании нового класса прибора на базе AbstractDevice, написать собственную логику функции init().
  - `labels` Возвращает список подписей для линий на графиках. Если у прибора 1 канал, возвращает просто имя. Если каналов больше одного, генерирует список с номерами каналов.
  - `keys` Работает аналогично labels, но возвращает список ключей для внутренних словарей, переводя имя прибора в нижний регистр.

  - `init`

  - `get_beam_state` Включен или выключен лазер
  - `set_power_dbm` Задать мощность dBm
  - `set_wave_len` Задать длину волны
  - `start_scan` начать сканирование. Лазер быстро перестроится, на выходе SYNC будет синхросигнал. Его в триггер PM по BNC кабелю 
  - `connect` подключить
  - `store_state` сохранить состояние
  - `restore_state` восстановить состояние

### pm2100.py
- `PM_MODE_CONST1, PM_MODE_SWEEP1, PM_MODE_CONST2, PM_MODE_SWEEP2, PM_MODE_FREERUN` - константы, которые описывают режим работы прибора
- `__init__` Задает тип соединения, класс соединения и номер модуля.
- `set_timeout` Определяет, сколько секунд программа будет ждать ответа от измерителя по сети, прежде чем выдать ошибку таймаута.
-  `init` При подключении отправляет прибору запрос идентификации и устанавливает время усреднения.
- `set_wave_len` Устанавливает рабочую длину волны. 
- `get_power` Делает одиночный замер на конкретном канале.
- `get_module_cnt` Отправляет запрос MNUM?\r\n, чтобы узнать количество установленных измерительных модулей в PM2100
- `set_work_mode` Переключает режим измерения
- `set_sweep_range, set_sweep_speed` Настраивают параметры развертки для снятия спектра.
- `set_gain` Устанавливает уровень усиления.
- `set_trigger` Настраивает источник триггера.
- `get_gain` Опрашивает прибор, чтобы получить текущий фиксированный уровень усиления.
- `set_avg_time` Задает время усреднения сигнала в миллисекундах.
- `set_meas_cnt` Задает количество точек измерения, которые прибор должен записать во внутреннюю память.
- `run_zero` Устраняет электрическое смещение постоянного тока.
- `set_auto` Включает автоусиление.
- `get_auto` Делает запрос прибору, чтобы узнать, активирован ли в данный момент режим автоматического подбора усиления.
- `run_meas, stop_meas` Запускают и останавливают процесс непрерывного аппаратного измерения.
- `get_meas_state` Запрашивает статус прибора. Используется в цикле аппаратной синхронизации, чтобы понять, завершил ли прибор сбор данных.
- `get_err` Считывает внутренние ошибки прибора
- `get_meas_data` Скачивает из памяти прибора весь накопленный пакет данных после синхронного сканирования.
- `connect` Устанавливает связь с устройством.
- `disconnect` Корректно завершает работу. Если соединение существует и активно, функция вызывает метод закрытия порта.
- `startConst1` Подготавливает прибор к синхронному сканированию без автоусиления. Задает длину волны, включает внешний триггер, задает количество точек и начинает запись.
- `startConst2` Подготавливает прибор к синхронному сканированию в режиме автоусиления. 
- `startSweep2` Настраивает прибор для спектрального сканирования длины волны.

## PMapping
### measuring.py
- класс `PMapMeasureProcedures`
  - `__init__` Задает стартовые значения: размеры области сканирования, привязывает физические оси к переменным и создает пустые матрицы для записи результатов.
  - `save_anchor` Сохранение наилучших координат после успешного сканирования.
  - `blind_move_right_side` Стыковка "вслепую" правой стороной.
  - `set_platform` Переключает "флаги" между левой и правой платформой. Меняет внутренние индексы осей, чтобы одни и те же функции сканирования могли управлять разными моторами.
  - `save` Запоминает текущие пользовательские скорости моторов и применяет те, которые передаются в аргументы функции. В дальнейшем возможно вернуть пользовательские скорости вызовом метода restore
  - `restore` Возвращаем пользовательские скорости моторов, ускорения, замедления, которые сохранили, с помощью метода `save`
  - `draw_scale` Рисует легенду сбоку от графика.
  - `prepArray` Пробегается по массиву логарифмических значений мощности, находит минимум и максимум, а затем пересчитывает все значения в шкалу от 0 до 255 (для градаций красного цвета на тепловой карте).
  - `draw_map` Отрисовка карты интенсивности.
  - `scan_manual` Асинхронное сканирование, позиционер едет строку без остановки, а измеритель опрашивается так часто, как успевает. После совершаем шаг по z. Движение рисует образ "змейки" 
  - `scan_auto` Не используется. Версия scan_manual с высокими скоростями и обязательным возвратом в найденный максимум. Возврат сломан (вызывается несуществующий z_platform.set_platform_pos)
  - `aiming` 
  - `process_crosshair` Вызываем в цикле, проверяем, соответствует ли положение квадрата заданной точке. Если не соответствует - удаляем старый квадрат и рисуем новый в нужных координатах
  - `process_horiz_aiming` Обрабатываем нажатие по карты в режиме корректировки горизонта
  - `correct_horizont_sync` Строят сразу две карты для крайних каналов волновода, находят два пика интенсивности и передают их высоты.
  - `correct_horizont_manual`
  - `correct_horizont_linear` Юстировка крена, использующая только ось Z. 
  - `correct_pitch` Не используется. Сканируем ось продольного наклона, чтобы торец волокна был строго параллелен торцу чипа. Была написана до появления боковой камеры
  - `scan_manual_sync` Сканирование с синхронизатором. Позиционер движется не останавливаясь, а измеритеоль делает замеры по электрическим импульсам от контроллера синхронизации.
  - `horizont_platform_correction` Принимает разницу высот из прошлых функций и по вычисляет угол перекоса, после чего поворачивает платформу на этот угол.
  - `adjustment_l_and_r` Функция юстировки, которая поочерёдно запускает сканирование правой и левой платформ (методы start_adjustment_l_and_r_thread и adjustment_l_and_r_logic представляют из себя создание отдельного потока и содержание логики сканирования соответственно)
  - `scan_manual_2, scan_manual_3` Версии методов сканирования, во втором пошаговое передвижение по оси x и перемещение по y "пробегом", в третьем наоборот.   
  - `adjustment_all` Не используется. Вызываем `start_adjustment_all_thread` и выводим всплывающее окно с надписью "ВКЛЮЧИТЕ ШИРИК" 
  - `start_adjustment_l_and_r_thread` Вызываем `adjustment_l_and_r_logic` в отдельном потоке
  - `adjustment_l_and_r` Вызываем `start_adjustment_l_and_r_thread` и выводим всплывающее окно с надписью "ВКЛЮЧИТЕ ШИРИК" 
  - `scan_manual_sync` Сканируем одну сторону(правый или левый позиционер) с синхронизатором, переезжает в максимум или на позицию до сканирования в зависимости от `after_measure`

## meas_powermap.py
- `set_platform_pos` Отвечает за ручное управление. Когда пользователь кликает по карте интенсивности на экране, эта функция берет экранные координаты клика переводит их в координаты моторов и отправляет их в эту точку.
- `recalc_um` Срабатывает, когда пользователь двигает ползунок шага в интерфейсе. Переводит микроны в шаги двигателя и обновляет текстовые метки на экране.
- `set_powermap_measure_params` Передает количество строк, ширину, шаг сканирования и проверяет, подключены ли измерители и моторы. Если какие-то из приборов не готовы, метод выдаст предупреждение и блокирует старт.
- класс `MeasurePowerMap`
  - `__init__` Вызывается для создания объекта и подготавливает пустые «ячейки» для будущего интерфейса.
  - `mode_sel_callback` Обработчик кнопки «Режим измерения». Если выбран режим «Выравнивание горизонта», функция отображает второй выпадающий список каналов, поле для ввода расстояния между датчиками и показывает второй график на экране.
  - `plot_callback, plot_callback2` Обработчики кликов мыши по графикам. Считывают координату клика и либо отправляют туда мотор, либо рисуют там маркер.
  - `measure_powermap_callback` Кнопка — «Провести измерение». Считывает все данные из интерфейса, передает их, а затем запускает математическую функцию в зависимости от выбранных режимов.
  - `prepare` Рисует главный график meas_chart и заполняет его. Затем создает элементы управления: выбор платформы, режим измерения, выпадающий список приборов и настройки шага сканирования.
  - `select_pm_chan, select_pm_chan2` Считывают выбранный канал. Если выбран второй модуль (PM2100_2), к номеру канала прибавляется 20, если третий — 40, чтобы программа понимала сквозную нумерацию.
  - `powermap_loop` Функция, которая крутится в бесконечном главном цикле интерфейса. Если открыта вкладка TAB_POWERMAP_ID, она постоянно перерисовывает маркер-перекрестие поверх графика, чтобы он следовал за мышкой или мотором.

- `select_pm` Срабатывает при выборе прибора измерителя. Пробегается по массиву активных каналов и отмечает только те каналы, которые реально включены в настройках этого прибора.
